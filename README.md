# What We Fed

A short 2D pixel game built in Java, following RyiSnow's "How to Make a 2D Game in Java" tutorial as a base.

## Play now
🎮 [Download on itch.io](https://mugeisbored.itch.io/what-we-fed)

## About
A short, story-driven game about a woman keeping herself and her daughter fed and safe from something outside.

## Status
Playable and complete (v1.0) — actively being improved. See [Roadmap](#roadmap) below for planned additions.
